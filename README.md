# Тренажёр по основам экономических знаний

Статический сайт из `index.html`, `questions.html`, `styles.css`, `app.js` и `questions.json`. Готовые файлы для GitHub находятся в папке `site-for-github-pages`.

## Публикация на GitHub Pages

Загрузите содержимое папки `site-for-github-pages` в корень репозитория. В настройках репозитория включите Pages с источником **Deploy from a branch**, веткой `main` и папкой `/ (root)`. Сайт будет доступен по адресу, который покажет GitHub Pages.

`questions.json` загружается через `fetch`, поэтому для локальной проверки откройте сайт через HTTP. Например, в папке `site-for-github-pages` выполните `python -m http.server 8765` и перейдите на `http://localhost:8765/`.

## Источник и перенос данных

Единственный источник вопросов: `База_Основы_экономических_знаний.docx`. В `questions.json` у каждой записи указаны модуль, номер абзаца и номер изображения в Word. Варианты распознаны со скриншотов Word как текст, а правильные ответы определены по зелёным рамкам. Автоматическое распознавание может содержать ошибки, поэтому перед публикацией варианты нужно сверить с Word.

Сводка по модулям находится в [IMPORT_REPORT.md](IMPORT_REPORT.md). Два вопроса без вариантов проходят со свободным вводом ответа. Исходные изображения в `source-images` и скрипт `build_data.py` нужны только для повторного извлечения данных; опубликованному сайту они не требуются.
