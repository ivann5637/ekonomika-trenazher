# Тренажёр по основам экономических знаний

Тренажёр помогает самостоятельно повторять основы экономики и проверять знания по учебным вопросам. Можно заниматься в режиме тренировки или пройти проверку знаний, выбирая нужный модуль. Вопросы и варианты ответов представлены текстом.

## Файлы проекта

- `IMPORT_REPORT.md` — краткий отчёт о составе вопросов по модулям.
- `app.js` — логика тренажёра: показ вопросов, проверка ответов и переключение режимов.
- `index.html` — главная страница с выбором режима и раздела.
- `questions.html` — страница со списком вопросов.
- `questions.json` — вопросы, варианты ответов и правильные ответы.
- `styles.css` — оформление страниц и элементов тренажёра.
